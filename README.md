# InDesign & XML Publishing Automation Portfolio

Enterprise-grade desktop automation tools (VB.NET, ExtendScript/JSX, COM Automation, XSLT) designed to streamline publishing workflows, enforce quality assurance, and eliminate manual bottlenecks in Adobe InDesign and XML production pipelines.

## Key Performance & Impact Metrics

| Automation Solution | Primary Technology | Key Impact & Time Savings |
| :--- | :--- | :--- |
| **InDesign XML Processing Tool** | VB.NET, COM, Saxon XSLT, VTool | **94% time reduction** (~2.8 hours saved per 20-chapter book) |
| **Print PDF Automation Tool** | InDesign Scripting, Preflight API | **65% faster processing** (Reduced from 20 mins to 6 mins per file) |
| **AutoCI Indexing Tool (v2.0)** | XML Diff Engine, AutoPage | **90%+ accuracy rate** (Up from 42–50% in v1.0) |
| **InDesign Auto QC Sentinel** | VB.NET, Live COM Polling | Continuous 60-second background validation; zero late-stage surprises |
